# Projeto Jogo TikTok — Duelo Live

Estrutura organizada conforme o repositório:
- `public/gifts/white-rose.png`: rosa branca transparente
- `src/main.jsx`: lógica do placar e cronômetro
- `src/styles.css`: interface responsiva
- `supabase/`: pasta reservada para futura integração
- `index.html`, `package.json`, `package-lock.json` e configurações na raiz

## Executar
Requer Node.js LTS. Na pasta do projeto:
```bash
npm install
npm run dev
```
Para criar a versão de produção:
```bash
npm run build
```
Os presentes são registrados manualmente. Esta versão não detecta presentes automaticamente no TikTok.
